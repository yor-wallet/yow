# DOOM | دوم — Cahier des charges (condensed, authoritative for implementers)

Premium electronics marketplace, Sultanate of Oman. Currency **OMR** (store money as integer **baisa**, 1 OMR = 1000 baisa; display 3 decimals). Languages **ar (default, RTL), en, fr**. Goal: production-grade, visually superior to Noon, *without copying Noon*.

## Absolute rules
1. Name exactly `DOOM | دوم`. 2. Official logo only: `brand-src/doom-logo-official.png`; derived assets in `public/brand/*` and `public/icons/*` (generated by `scripts/generate-icons.mjs`). Never redraw/recolour/distort the logo. Transparent logo variants are for **dark** surfaces only; on light surfaces use `doom-logo-*-light.*` (logo on its violet plate).
3. Colours (below) only. 4. No fake features, no inactive buttons, no simulated payments. 5. **Never invent prices or stock.** Seed data may contain categories/brands/zones/campaign copy but **no product prices or stock**; products are created by admins. 6. Never show a payment as confirmed without real provider/admin confirmation. 7. Every page responsive 320px→2560px, no horizontal overflow, no layout shift. 8. Every Back button works (see Navigation). 9. Animations optimised, `prefers-reduced-motion` respected. 10. Security of data (KYC encrypted, roles, audit log). 11. Test everything. 12. Integrations requiring contracts/credentials (Ooredoo, Omantel, card gateway, crypto, FLEX finance partner) are implemented as real adapters behind env config; when not configured they are shown as **unavailable** (disabled with explanation) — never faked.

## Responsive / stability
Breakpoints (guides): 320, 375, 430, 768, 1024, 1280, 1600. Fluid grids, clamp(), minmax(), container queries.
Viewport: `width=device-width, initial-scale=1, viewport-fit=cover` — **never** `user-scalable=no`/`maximum-scale`. Inputs ≥16px font. `html{overflow-x:clip}` `body{min-height:100dvh}` `img,video,canvas{max-width:100%}`. Safe-area insets. Keyboard must not hide focused inputs (`interactive-widget=resizes-content`, scrollIntoView on focus in sheets). Modals never off-screen (max-height 100dvh, internal scroll).
Mobile: fixed bottom nav **Accueil — Catégories — Panier — Commandes — Profil**, large touch targets (≥44px). Desktop: full header nav, advanced search, mega-menu dropdowns, product grid with side filters, detailed cart, adapted admin.

## Navigation & Back
Every secondary page has a visible Back button (arrow + page title on mobile; arrow mirrored in RTL). Back = `router.back()` if there is in-app history, else a safe fallback route per page (never loops, never leaves site on direct open). Preserve cart (server+localStorage), filters (URL search params), non-sensitive form drafts (sessionStorage). Android back / iOS swipe / browser back all work (use real history, no hash hacks). Modals/sheets: Back closes the modal first (push a history entry when opened, pop on close). Checkout/payment: back never re-triggers a payment; payment state always re-read from the server; idempotency keys on every payment/order mutation. Confirm before abandoning an important step.

Admin campaign manager: create/edit, upload image/video (PNG, JPEG, WebP, AVIF, MP4, WebM, Lottie JSON), texts per locale, start/end dates, linked products, target pages/placements, priority, active toggle, stats (impressions/clicks recorded server-side).

## Prices & stock
Admin: create product/variants, price, stock, images, specs, disable sale, promotions. Price engine: admin records market observations (source name, URL, price, date, verified flag — manual entry from authorised sources, no scraping), purchase cost, costs; system computes market average, recommended price (target margin), margin, estimated profit, and labels verified vs estimated. Stock reservations at checkout with expiry.

## DOOM Wallet
Per-customer OMR wallet: balance, top-up, pay with balance, history, refunds, downloadable receipts (PDF). Double-entry **ledger**, atomic DB transactions (SERIALIZABLE or row locks), unique references, idempotency keys, server-side checks, reconciliation report. Credit only after real confirmation (gateway webhook verified, or admin verification of actually-encashed value for gift cards).

## Payments
Adapters: Ooredoo Oman, Omantel (mobile carrier billing via official merchant APIs), cards (Visa/Mastercard via a local gateway e.g. Thawani Pay / bank gateway), crypto (BTC, ETH, USDT, USDC via licensed provider), gift cards (submission → admin verification → confirmation of encashed value → wallet credit; never credit on code/screenshot alone). Flow: choose method → secure transmission → validity check → confirmed encashed value → wallet credit → order payment. Unconfigured providers display "unavailable".

## DOOM FLEX
3/6/12 months, 0% interest, no fees, total = cash price, transparent schedule (e.g. 360 OMR → 120/60/30). Last instalment absorbs baisa rounding. Flow: product → FLEX → duration → identity verified (KYC required) → submit application → admin/partner decision → customer accepts terms → confirm → schedule; instalment tracking & payment (wallet).

## Delivery — DOOM EXPRESS
Standard target 24h, Express target 6h (extra fee by zone, distance, weight, volume, availability, urgency; admin-configurable zones/rates). Address: name, phone (+968), address, governorate (11 Omani governorates), wilaya, area, building, GPS (geolocation), instructions. Tracking: confirmed → preparing → packed → courier assigned → out for delivery → delivered. Handover OTP + proof of delivery (photo/signature name). Promised times must match configured capacity.

## Account verification (KYC)
Basic: full name, phone, email, address. Enhanced: ID front, ID back, selfie, admin review. Statuses: unverified, pending, documents_requested, verified, rejected. Files encrypted at rest (AES-256-GCM, key from env), private storage, access only to authorised roles, access logged, data minimisation.
